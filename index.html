Under Staffed

 +
Gameplay Programming UI / UX Unity / C#

The gameYou run a chronically understaffed business and have to juggle workers, stations, and customers to keep everyone happy and keep your job.

My roleI built the core worker system: drag-and-drop worker control, area assignment, and the behavior for every work station.  +
Procedural Generation Multiplayer 3D Modeling Lighting Post Process UI / UX Unity / C#

The gameA multiplayer extraction horror game built around procedural generation. The goal is dread through isolation: even with friends in the same session, the station should make you feel alone.

04

Shift

Solo project · gravity-switching first-person arena shooter

 +
Unreal / Blueprints Lighting Level Design

The gameA casual, arcade-style movement shooter where stepping onto a plane flips your gravity. Built for 3v3 play across several game modes, with levels designed so players can find creative routes through fights.

My roleI designed the gravity orientation mechanic, which uses volume triggers to reorient players to new surfaces. I also built a weapon and ability system that players choose at spawn, then designed and lit multiple levels so every angle of the map reads cinematically, whichever way "up" happens to be.

What it taught meShift was my first project that outgrew its scope. Cutting features, locking down a core mechanic, and planning around constraints are lessons I now apply from the first day of every project.

About

I've been taking games apart to see how they work since I was young. I started with tutorials and solo experiments, and the project that taught me the most was Shift. It was far out of scope, and that gap taught me what actually matters in game design: a clear core mechanic, honest scoping, and finishing what you start. I apply those lessons to every project now.

I'm a Digital Media student at the University of Central Florida, graduating in Spring 2027. Along the way I found technical art, which sits between modeling and programming and lets me do the most for a team. I'm happiest when I can build the system, model the assets, and light the scene so it all works together.

Right now I'm working on team projects for Workshop and Casual Game Production alongside my own project, Station. I check in with leads before making changes, and I write modular, optimized, well-commented code so teammates can pick it up without me.
